Oversightboard.com site-wide CSRF due to missing checking

Jun 27, 2021

Description

This bug could allow an attacker to force a user in Oversightboard.com who visited his website, to make certain requests which would allow the deleting, editing or creating of data. This is possible because the website www.oversightboard.com  doesn't implement any security measurements like special token or headers to prevent CSRF attacks. The attacker would first exploit a Login CSRF bug which would force a Facebook or Instagram logged-in user to login in the www.oversightboard.com and then exploit the CSRF bug to make different actions.

Details
